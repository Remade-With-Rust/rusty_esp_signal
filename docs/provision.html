Web Bluetooth, no app. Open this page over https:// (or localhost) in Chrome or Edge on a phone or laptop, press Connect and pick the device, type the setup code you were given with it, then choose a network. The code unlocks an encrypted session with that device alone: the passphrase leaves this page sealed, and nothing is shown, stored or logged in the clear.
